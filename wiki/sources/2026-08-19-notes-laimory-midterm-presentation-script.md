# Laimory 중간점검 발표 대본

## Summary

50쪽 당시 발표자료를 기준으로 20분 제한 안에서 30초 시연을 포함해 약 19분 25초로 구성한 발표 대본이다. 각 page가 전달할 주장 하나를 중심으로 49개 발표 구간과 전환 문구를 배치하고, 인쇄용으로는 A4 가로 2단 5쪽 PDF를 만들었다.

## Key Claims

- 문제·시장·사용자보다 개발 진행현황과 AI pipeline, 제품 검증에 더 긴 시간을 배정한다.
- 앱 시연은 개발 진행현황 개요 직후 30초로 배치한다.
- 표의 모든 항목을 읽지 않고 평가자가 기억해야 할 주장 하나를 page별로 설명한다.
- 35초의 여유 시간을 slide 전환, 영상 재생 지연과 호흡에 사용한다.
- 인쇄 PDF는 5쪽 모두 열리고, 2026-08-20 렌더 검수에서 clipping이나 page 누락이 보이지 않았다.

## Caveats

- 대본이 참조한 deck은 50쪽 버전이다. 현재 `raw/pdf/라이모리 중간 발표.pdf`는 전환 page가 포함된 63쪽 버전이므로 현장 사용 전 page mapping을 다시 확인해야 한다.
- 발표 문장은 보고서·당시 구현 상태를 압축한 talk track이며 기술 계약의 정본이 아니다.
