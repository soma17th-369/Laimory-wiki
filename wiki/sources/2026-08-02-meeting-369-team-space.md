### 타임라인 품질과 모델 비교

- 현재 타임라인 생성에 사용 중이라고 언급된 모델은 전사상 `GPT 5.4 mini`이며, 7월 31일 사례 한 건의 비용이 Langfuse 기준 약 70원이라고 보고됐다. 상위 모델을 웹 UI에서 실행했을 때는 약 140원으로 두 배 수준이라는 설명이 뒤따랐다. 모델명과 금액은 자동 전사 오류 가능성이 있어 실제 trace와 billing에서 확인해야 한다. (`01:08-02:23`)

- 우수 결과를 모범 사례로 삼아 현재 agent 결과와 비교·채점하는 자동 평가 아이디어가 제안됐다. 구체적인 rubric과 평가 신뢰도는 아직 설계 전이다. (`05:39-06:25`, `11:14-12:55`)

### User Memory 설계

- 사용자별 비정형 정보를 저장하는 User Memory가 타임라인 품질에 중요하다는 판단이 공유됐다. 데이터는 JSON 형태가 될 가능성이 있으며, 별도 저장소를 User table과 연결할지 User table의 한 column으로 둘지 검토 중이었다. (`05:19-05:36`, `13:11-13:39`)
- 사용자가 AI 초안을 직접 수정한 뒤 저장한 타임라인을 기준으로 memory를 갱신해야 한다는 방향은 있었지만, 저장 직후 API call을 할지 batch로 처리할지와 정확한 갱신 시점은 미결이었다. 발언자는 이 작업이 아직 설계 단계라고 명시했다. (`13:39-14:12`)

- cloud, AI token, marketing 비용을 함께 고려하면 기존 예산이 빠듯하다는 보고가 있었다. 월 서버·logging·monitoring·AI runtime 비용을 합친 추정치가 약 88만원으로 언급됐지만, 요청량과 실제 CPU·memory 사용량을 알 수 없어 rough estimate라고 설명했다. (`14:34-22:15`)
