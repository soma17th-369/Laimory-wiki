# Laimory 프로젝트 중간점검 발표자료 초안

AI·SW마에스트로 제17기 369팀 프로젝트 중간보고서의 내용과 서술 순서를 기준으로 만든 인간 검토 대기 발표자료다.

## 산출물

- [PPTX 초안](2026-08-16-laimory-midterm-presentation-draft.pptx)
- 본편 20장과 질의응답용 부록 5장
- 모든 슬라이드에 쪽번호와 중간보고서 페이지 기반 발표자 노트 포함

## 구성 원칙

- 평가항목을 목차로 삼지 않고 중간보고서의 문제 정의, 제품 범위, 구현 현황, 기술 상세, 검증 계획, 사업·일정 순서를 유지했다.
- 중간보고서의 시장 사례, 시스템 구성도, AI 파이프라인, Evaluation System 화면을 발표 맥락에 맞게 사용했다.
- 20분 본 발표에서는 1~20장을 사용하고, 21~25장은 질의응답 근거로 사용한다.
- 인간 검토와 수정 승인이 있기 전에는 `wiki/`에 인제스트하지 않는다.

## 검토 상태

- PPTX 렌더링 전체 25장 육안 검수 완료
- 오버플로 및 잘림 자동 검사 통과
- 제출 전 PowerPoint에서 최종 문구·발표 시간·폰트 호환성을 확인한 뒤 PDF로 변환해야 한다.
