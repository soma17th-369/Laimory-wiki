# Laimory 신규 기능 가치 제안 초안

## 출발점

`일기를 잘 쓰게 한다`는 기능 설명에 가깝다. 사용자가 얻는 최종 가치는 글쓰기 실력의 향상보다 다음 변화에 있다.

> 흘려보낼 뻔한 하루를 쉽게 붙잡고, 남이 만든 요약이 아니라 내가 느낀 의미가 담긴 나의 기록으로 완성한다.

기존 회고 기능이 축적된 과거를 돌아보고 패턴과 변화를 발견하는 역할이라면, 신규 기능은 기록하는 순간의 어려움을 줄이는 데 집중한다.

## 해결할 사용자 문제

사용자가 일기를 쓰지 못하는 이유는 쓸 것이 없어서가 아니다.

- 하루의 구체적인 장면이 바로 떠오르지 않는다.
- 있었던 사실은 기억하지만 무엇을 느꼈고 왜 중요했는지 말로 옮기기 어렵다.
- 빈 화면에서 처음부터 글을 구성하는 일이 부담스럽다.
- 잘 써야 한다는 압박 때문에 시작하거나 끝내지 못한다.
- 자동 생성된 문장은 편하지만 자신의 기록처럼 느껴지지 않는다.

## 제안하는 핵심 가치

### 기억의 복원

사진, 위치, 일정 등 하루의 흔적을 단서로 제공해 사용자가 잊고 있던 장면을 쉽게 떠올리게 한다.

### 자기표현의 보조

AI가 사용자를 대신해 감정을 단정하거나 일기를 완성하지 않고, 구체적인 질문과 표현 후보를 제공해 사용자가 자기 경험을 자기 말로 남기게 한다.

### 기록 완성의 성취

완성도 높은 장문보다 짧더라도 진짜 자기 생각이 담긴 기록 하나를 끝내게 한다. 사용 후 즉시 얻는 보상은 분석 결과가 아니라 `오늘도 내 하루를 남겼다`는 안도감과 성취감이다.

### 삶의 소유감

자동 수집된 데이터가 서비스의 기록으로 끝나지 않고, 사용자가 선택하고 수정하고 의미를 부여한 자신의 이야기로 바뀌게 한다.

## 제품 원칙

- AI는 대필자가 아니라 기억과 표현을 돕는 편집자여야 한다.
- 질문은 `오늘 어땠나요?` 같은 추상 질문보다 특정 사건에 근거해야 한다.
- 사실 자동화와 의미 자동화를 구분한다. AI는 사실을 정리할 수 있지만 의미와 감정의 최종 결정권은 사용자에게 둔다.
- 긴 글을 강요하지 않는다. 한 문장, 감정 하나, 사진 설명 하나도 완성된 기록으로 인정한다.
- 처음부터 빈 화면을 주지 않되, 자동 생성문을 그대로 승인하는 수동적 경험도 피한다.
- 사용자가 입력한 문체와 표현을 존중하고 과도하게 교정하지 않는다.

## 기능 방향 후보

### 장면 기반 한 문장 질문

타임라인의 특정 사건을 바탕으로 답하기 쉬운 질문 하나를 제시한다.

- `성수동 카페에서 가장 기억에 남은 건 뭐였나요?`
- `이 사진을 다시 봤을 때 가장 먼저 떠오른 생각은 무엇인가요?`

사용자는 짧게 답하고, 답변은 해당 장면의 기록에 자연스럽게 붙는다.

### 말로 남기고 글로 다듬기

사용자가 부담 없이 말하면 AI가 의미를 바꾸지 않는 범위에서 읽기 좋은 문장으로 정리한다. 원문과 정리본을 모두 확인하고 선택할 수 있어야 한다.

### 기억 조각 선택하기

하루의 사진·장소·일정 중 `남기고 싶은 장면`만 고르면 AI가 기록의 뼈대를 만든다. 모든 데이터를 일기로 만드는 대신 사용자의 선택 자체가 의미 부여가 된다.

### 표현 도움 받기

사용자가 쓴 짧은 문장을 바탕으로 `조금 더 구체적으로`, `내 말투를 유지해서`, `한 문장으로` 같은 선택지만 제공한다. 점수나 문법 평가보다 표현의 마찰을 줄이는 데 집중한다.

## 추천 가치 문장

### 제품 내부 기준

> Laimory는 사용자가 하루를 더 잘 평가하게 하는 앱이 아니라, 사라질 하루를 자기 언어로 남길 수 있게 하는 앱이다.

### 사용자용 표현

> 기억은 찾아주고, 이야기는 당신이 완성해요.

또는:

> 막막한 일기 대신, 오늘의 한 장면부터.

## 회고 기능과의 경계

| 구분 | 신규 기록 기능 | 기존 회고 기능 |
|---|---|---|
| 시점 | 오늘 또는 기록하는 순간 | 축적된 과거 |
| 핵심 문제 | 기억과 표현의 막막함 | 패턴과 변화의 발견 |
| AI 역할 | 단서 제공, 질문, 표현 보조 | 요약, 비교, 분석 |
| 즉시 보상 | 내 기록을 완성했다는 성취 | 나를 새롭게 이해했다는 통찰 |
| 사용자 주도권 | 의미와 감정 직접 선택 | 분석 결과 확인·해석 |

## 우선 검증할 가설

가장 먼저 검증할 것은 `AI가 더 좋은 글을 만들어주는가`가 아니다.

> 구체적인 하루 단서와 하나의 질문을 받으면, 사용자는 빈 화면보다 더 쉽게 자기 생각이 담긴 기록을 완성하는가?

초기 실험에서는 다음을 비교한다.

- 빈 일기 화면 대비 첫 입력 시작률
- 질문 노출 후 답변 완료율
- 최종 기록 저장률
- 자동 생성문 수정률과 사용자 직접 문장 비율
- `내가 쓴 기록처럼 느껴진다`는 정성 응답
- 다음 날 다시 기록한 비율

## 기획 시 피해야 할 방향

- AI가 감정과 의미까지 추론해 완성문을 대신 써주는 기능
- 글쓰기 점수, 맞춤법 점수처럼 사용자를 평가하는 경험
- 모든 사건에 질문을 붙여 새로운 기록 노동을 만드는 방식
- 장문 일기 완성을 성공 기준으로 삼는 방식
- 회고·패턴 분석과 이름만 다른 요약 기능

## 제안 결론

신규 기능의 1차 가치는 `일기 작성 능력 향상`보다 `기록할 수 있다는 자기효능감`으로 잡는 것이 적합하다. 이를 통해 사용자는 하루를 잃지 않고, 자동 수집 데이터에 자기 의미를 더하며, 자신의 삶을 스스로 소유하고 있다는 감각을 얻는다.
