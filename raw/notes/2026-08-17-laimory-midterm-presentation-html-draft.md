## 이전 초안 대비 변경 사항

- 슬라이드 푸터의 `중간보고서 p.X` 표기 제거 (보고서 복사본으로 읽히는 문제)
- 개발 진행현황 12장 → 22장으로 확대, 전체의 43% 배분
- 보고서에서 누락되어 있던 기술 의사결정 내용 복원
  - LangGraph vs CrewAI vs AutoGen 프레임워크 선정 근거
  - 경량 멀티모달 LLM 3종(GPT-5.4 mini · Gemini 2.5 Flash · Amazon Nova 2 Lite) 비교 평가
  - Bedrock AgentCore On-demand 전환 계획, Elasticsearch / Langfuse 관측 분리
  - Kotlin · Compose · Clean Architecture + MVI, 부하 테스트·오토 스케일링 리스크 대응
  - 담당멘토 3인의 보완 지적을 멘토 구성 슬라이드에 반영
- `구현 완료 / 진행 중 / 예정` 상태 칩을 도입하여 실제 진척과 계획을 구분
- 목표 추적 기능이 MVP 범위이면서 미구현임을 명시 (이전 초안은 범위만 표기)
- 구독 가격의 근거였던 경쟁 서비스 연 구독료 비교표 복원
- Evaluation System 슬라이드에 실제 채점 결과 수치 반영 (종합 5/10, 문제점 11건, 기준별 4~8점)

## 레이아웃·톤 정리

- 슬라이드마다 눈대중으로 넣던 `margin-top` 제거, flex 기반 고정 베이스라인으로 전환
- 전 슬라이드 콘텐츠 하단이 푸터 위 16px에 정렬됨 (이전 초안은 372~640px로 최대 270px 편차)
- 색을 컬럼 순서가 아닌 의미로 사용: 파랑=강조, 초록=구현 완료, 주황=예정·검증 필요
- 팀원 이름을 지표용 큰 숫자 스타일로 렌더하던 문제 수정
- `A가 아니라 B` 수사 구문 12회 → 5회, 하단 마감 문구는 사실 정보를 담은 경우로 한정

## 남은 인간 확인 사항

- **앱 실행 화면 캡처 미삽입** — 20번 슬라이드에 자리(점선 프레임)만 잡아 둠. 보고서 코멘트에서도 요청된 항목이며, App Tester 설치 화면과 타임라인 화면 캡처가 필요하다.
- 알파 테스트 정량 결과(생성 건수, 실패율, 수정·삭제 비율)가 확보되면 20번 슬라이드 지표 카드에 반영 필요.
- LLM 3종 비교 평가 결과가 나오면 31번 슬라이드를 `진행 중`에서 결과 표로 교체 필요.
- 인간 검토와 수정 승인이 있기 전에는 `wiki/`에 인제스트하지 않는다.
