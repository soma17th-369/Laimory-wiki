릴리스 및 다음 단계: Play Store 심사 완료까지 내부 테스트는 디버그 빌드를 사용합니다; 전형선이 심사 거부 후 사소한 설명 변경을 재제출했으며 빠른 해결을 예상합니다. 팀은 출시 후 광고 최적화 및 KPI 추적을 계속할 것이며, 크레딧/결제 API 완성 및 추가 서버 연동을 우선순위로 둡니다 (이동건). 액션 아이템: 전형선은 크레딧 확인 대화상자 및 팝업 UI 구현; 정수현은 변수->DB 마이그레이션 완료; 팀은 로딩 타이밍 재조정 및 AI 정확도 공지 추가; 모두 업데이트된 디버그 빌드를 테스트하고 출시 후 광고 지표를 검증합니다.
상세 요약
AI performance metrics
팀은 최근 AI 개선 및 초기 사용 지표(전환율 및 재현율)를 검토했습니다. 논의는 비용을 절감하면서 성능을 유지하고 사용자 기대를 관리하는 데 초점이 맞춰졌습니다. 현재 상태: 전환율 약 5%, 재현율 약 4.8%이며 기록부담(기록부담) 지표가 다소 선행하고 있습니다.
이동건은 최근 AI 작업 이후 전환율이 약 5% 근처를 유지하고 재현율이 약 4.8%로 떨어졌다고 보고합니다.
정수현은 동일 광고에서의 반복 방문자가 전환율 감소를 설명할 수 있으며 광고 재사용 효과를 지적합니다.
이동건은 팀이 광고 크레딧으로 ₩50,000을 부과하고 결과를 모니터링하여 AI 기반 기능을 최적화하고 있다고 말합니다.
Landing page redesign
애니메이션과 더 명확한 데이터 설명을 포함한 랜딩(랭킹) 페이지 재설계가 구현되어 광고 예시를 반영하고 기록의 출처를 보여줍니다. 이는 사용자 이해도를 높이고 참여를 증가시키는 것을 목표로 합니다. 현재 상태: 새로운 애니메이션 홈/랜딩 흐름이 디버그 빌드에서 라이브이며 검토 가능합니다.
이동건은 랜딩 페이지에 이제 애니메이션이 포함되고 광고의 예시 데이터를 복사해 기능을 명확히 했다고 설명합니다.
이동건은 페이지가 확장 가능한 상세 정보를 통해 개인 기록의 출처를 보여 투명성을 제공한다고 언급합니다.
전형선은 두 번째 화면과 애니메이션 추가가 앱을 실제 제품에 더 가깝게 느끼게 하며 피드백에 따라 반복 개선할 것이라고 확인합니다.
Cache and configuration changes
백엔드 작업으로 하드코딩된 변수를 코드에서 데이터베이스로 옮겨 다중 서버 배포 시 불일치를 방지합니다. 이는 구버전/신버전 서버 간 크레딧 소비 보고의 불일치 위험을 줄입니다. 현재 상태: 캐시 작업은 완료되었고 남은 변수->DB 마이그레이션이 진행 중입니다.
정수현은 캐시 작업을 마쳤고 배포 시 불일치를 피하기 위해 코드화된 변수를 DB로 이동하기로 결정했다고 보고합니다.
전형선은 변수에 대해 확인 질문을 하고 혼합 서버 버전이 서로 다른 크레딧 소비를 기록할 위험을 확인합니다.
이동건과 정수현은 다중 서버 아키텍처가 배포 중 공유 값의 신중한 처리를 필요로 한다는 데 동의합니다.
Home-to-loading navigation & credit dialog
클라이언트 측 변경으로 홈에서 로딩으로의 전환을 즉시 수행하면서 네트워크 및 콜백 보호 장치를 추가합니다. 팀은 타임라인 생성 시점의 남은 크레딧과 소비된 크레딧을 보여주고 크레딧이 부족할 경우 충전으로 유도하는 확인 대화상자를 정의했습니다. 현재 상태: 대화상자 디자인 및 API 체크가 진행 중이며 결제/크레딧 API는 아직 완성되지 않았습니다.
전형선은 네트워크/서버 실패에 대비한 콜백 처리를 추가하여 의도치 않은 앱 동작을 방지하며 즉시 네비게이션을 구현했다고 설명합니다.
전형선은 크레딧 소비 및 남은 크레딧을 보여주는 확인 대화상자를 제안하고 크레딧이 부족하면 생성 버튼을 충전 흐름으로 변경할 것을 제안합니다.
전형선은 크레딧 결제 API가 완성되지 않았고 서버 API가 생기면 소비 로그를 나중에 추가할 것으로 예상한다고 언급합니다.
Popup/notice implementation
팀은 팝업 공지의 서버 vs 클라이언트 처리와 사용자가 공지를 닫을 수 있는 방법(예: '오늘은 보지 않기')에 대해 논의했습니다. 관리자가 제공하는 유연한 공지 목록을 사용하기로 결정했고, 사용자별 해제를 위해 앱 측 관리를 선호하며 필요시 TTL 전략을 적용하기로 했습니다. 현재 상태: 명세에 합의되었고 전형선이 공지를 표시하고 앱에서 해제 상태를 처리하는 UI를 구현할 예정입니다.
정수현은 공지가 목록 형태로 전달되며 관리자에서 여러 항목과 가로 스크롤을 지원한다고 설명합니다.
전형선은 앱이 바텀 시트나 중앙 팝업으로 공지를 표시할 수 있고 제공된 목록 명세에 따라 구현할 것이라고 명확히 합니다.
정수현은 임시 '오늘은 보지 않기' 동작에 Redis TTL을 사용하는 것을 제안하고 전형선은 DB 복잡도 증가를 피하기 위해 사용자별 해제는 앱 측에서 관리하는 것을 선호합니다.
Loading screen behavior and UX
팀은 타임라인 생성 중 단계별 애니메이티드 로딩 화면을 평가했습니다. 우려는 단계별 시간 분배의 불균형과 마지막 AI 단계가 멈춘 것처럼 보이는 점에 집중되었습니다. 지속 시간을 재조정하고 로딩 피드백을 더 명확히(예: 애니메이션 표시기) 하며 AI 정확도에 대한 설명 경고를 남겨두기로 계획했습니다. 현재 상태: 단계 타이밍, 시각적 표시기 및 최종 메시징 개선이 계획되어 있으며 우선순위가 낮은 시각적 다듬기는 이후 진행됩니다.
이동건은 결과가 AI 생성이며 부정확할 수 있음을 짧게 표시해 사용자가 수정을 유도할 것을 권장합니다.
이동건은 마지막 AI 단계가 정적인 느낌을 주어 멈춘 것처럼 보일 수 있다고 지적하며 지속적인 동작이나 더 명확한 피드백을 제안합니다.
정수현과 전형선은 초기 단계(사진/위치/일정)에 더 많은 가시적 시간을 주고 마지막 AI 단계가 대기 채우기처럼 느껴지지 않도록 타이밍을 재조정하는 데 동의합니다.
App debug release and Play Store review
팀은 Play Store 릴리스가 검토 중이고 공개적으로 보이지 않기 때문에 내부 테스트에 디버그 빌드를 사용하기로 논의했습니다. 전형선은 최근 앱 심사 팀에서 요구한 사소한 설명 변경을 재제출했습니다. 현재 상태: 디버그 빌드가 표준 테스트 채널이며 Play Store 재제출이 진행 중이고 곧 해결될 것으로 예상됩니다.
전형선은 Play Store 심사에서 앱 설명(건강/수면 문구)이 문제로 지적되어 문제 문구를 제거하고 재제출했다고 보고합니다.
이동건은 테스터가 Play Store 버전이 검토 대기 중이므로 디버그 빌드를 사용해야 한다고 확인합니다.
전형선은 작은 제출 변경이 거부를 신속히 해결할 것으로 예상하며 다음 디버그 빌드 업로드 후 팀에 업데이트하겠다고 말합니다.
Ad performance by age and gender
예비 광고 지표는 젊은 연령대에서 CTR이 높고 여성의 반응이 더 강하며 정보형 광고가 성별에 따라 다르게 작동함을 보여줍니다. 팀은 출시에 후속하여 최적화를 계속하고 KPI를 수집할 계획입니다. 현재 상태: 초기 CTR 패턴이 확인되었고(특히 여성 관심과 30–40대 클릭 행동이 두드러짐) 출시 후 추가 A/B 및 카피 작업이 예정되어 있습니다.
이동건은 CTR이 젊은 사용자와 여성 쪽으로 치우치고 있으며 서로 다른 광고 크리에이티브가 다른 참여 패턴을 낸다고 공유합니다.
전형선은 정보형 광고가 부담형 광고와 다른 참여를 유도하며 남성은 후자에 더 반응한다고 관찰합니다.
이동건은 타임라인 링크 클릭이 30–40대 사용자에 집중되어 있으며 팀은 출시 후 적극적 마케팅과 KPI 추적으로 전환할 것이라고 말합니다.

작업 항목
- 전형선: 로딩 화면 애니메이션과 단계별 시간 분배(사진·일정·위치·AI)를 조정하고, 시각적 '처리 중' 피드백(반짝임 등)을 시안으로 만들어 적용해본다.
- 전형선: 크레딧 관련 API(잔여 크레딧·소비 크레딧)를 확인하고 확인 다이얼로그 설계(충전으로 이동 등) 초안을 만들어 팀에 공유한다.
- 이동건: 계속 진행 중인 AI 성능 개선 작업을 이어가고, 생성 결과 안내 문구(정확도/출처 경고)를 설계하여 적용 방안을 마련한다.
- 전형선: 앱스토어 심사 관련 누락된 설명 문구를 수정하여 재제출한 상태를 모니터링하고 결과를 팀에 공유한다.
- 정수현: 캐시에서 DB로 옮기기로 한 크레딧/사용량 관련 값의 DB 이전 작업을 수행하고 배포를 준비한다.
- 이동건: 이번 주 내로 마지막 점검을 마무리하고 다음 주 월요일부터 광고 문구와 캠페인 운영(플레이/문구 변경)을 시작 준비한다.
- 전형선: 앱 디버그 빌드 업데이트를 배포하여 이동건이 보고한 체크 표시·캐시 관련 버그를 재현/해결할 수 있도록 한다.
- 전형선: 팝업 공지 관련 API를 확인하고 이슈를 생성한 뒤, 앱에서 팝업 노티스 리스트를 받아 띄우는 방식의 명세를 마무리해 작업을 진행한다.
- 정수현: 팝업 공지의 동작 방식(여러 공지 스크롤, '오늘만 보지 않기' 등)과 TTL 옵션(예: Redis 이용) 제안을 정리하여 전형선에게 전달한다.
- 이동건: 정수현이 AI 생성 중 멈춘 상태라 한 작업을 회의 종료 후 확인하고 피드백을 제공한다.
