# 369팀 스페이스 회의 요약 - 2026-11-01

## 개요

API 비용 급증을 조사하다 로컬 개발 Agent 테스트의 실제 API 호출을 원인으로 보고했다. 장소 후보·GA4·알림을 묶은 server·AI·Android 업데이트를 조율하고 영상 광고를 재검토했다.

## 상세 요약

### 비용 급증

- **관측 보고**: Timeline 수가 크게 늘지 않았는데 10월 31일 API 비용 29달러, 당일 약 14달러를 언급했다. 청구 기간·model·개발/운영 호출별 내역은 검증되지 않았다. (`1:21-1:28; 3:26`)

### 개발 테스트 원인

- **자체 조사 결론·재발 방지안**: 로컬 환경 파일에 둔 API key로 개발 Agent가 실제 호출하며 20여 회 반복했다고 설명했다. 외부 유출이 아니라고 판단했지만 독립 보안 감사 결과는 아니다. 명시적 테스트·반복 한도 축소를 제안했다. 정확한 파일명은 전사상 EMB로 들려 환경 파일로만 기록한다. (`37:02-37:57`)

### 연동 배포

- **미배포·조율 계획**: Server production은 아직 배포하지 않았고, Android 심사·AI 반영·필수 version 전환을 소통하며 맞추기로 했다. 서로 다른 완료 시점을 하나의 배포 완료로 합치지 않는다. (`8:25-8:30; 10:19-10:22; 12:28-12:59; 40:56-41:14`)

### GA4

- **구현·시험 예정**: 신기능과 추가 지표를 위한 GA4 event를 mobile에서 구현하고 실제 로그를 확인한 뒤 배포하려 했다. 수신 완료 보고가 아니다. (`9:01-9:22`)

### 장소 후보

- **한계·보완안**: 사진 근거가 있으면 후보 검토가 유용할 수 있으나 사진이 없을 때 정확도가 제한되는 문제를 논의했다. 추가 vision 검토는 비용 조건부 아이디어다. (`15:14`)

### 영상 광고

- **관찰·대안**: 기존 이미지보다 영상의 성과가 좋지 않다고 보고하고 AI 도입부를 빼고 앱 소개 중심으로 짧게 해보는 안을 검토했다. 지표·동일 조건 비교가 없어 이미지의 인과적 우위를 확정하지 않는다. (`20:02-23:06`)

### 알림

- **미확정 원인·수정 계획**: 설정 시각보다 4~5분 늦는 사례를 조사했다. Exact/inexact·OS batching 설명은 확실히 확인하지 못했다고 했으므로 검증된 platform 정책으로 쓰지 않는다. 선택 범위 축소·알림 안내와 정확한 시각 전달을 검토했다. (`25:37-26:29; 33:43-36:59; 39:12-40:32`)

### 정산·보고서

- **계획**: 총 700달러 기준에서 기충전 99달러를 빼고 601달러 추가와 결제 문서 정리를 논의했다. 추가 700달러 납부 완료로 기록하지 않는다. 다음 날 최종보고서 준비를 시작할 예정이었다. (`38:05-38:39; 41:25-41:31`)
