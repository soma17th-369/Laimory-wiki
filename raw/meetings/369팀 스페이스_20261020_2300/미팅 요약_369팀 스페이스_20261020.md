- 전형선 — 디버그 앱 대시보드 캡처(설치수·리뷰·크레딧 표시 등 현재 상태)를 챌러(팀 채널)에 올려 팀의 현황 인식을 맞추고, 다운로드/설치 수 차이 관련 설명을 덧붙여 공유.
- 전형선 — 타임라인 이벤트에 위치 좌표를 표시하는 UI 시안(지도에서 이벤트 위치를 보여주고 누르면 상세 텍스트가 뜨는 흐름 포함) 초안을 제작해 이동건에게 전달하여 디자인·개발 난이도 논의 일정을 잡기.
- 이동건 — 일단 장소 선택 UX 도입안(후보 리스트, 직접 입력 칸, 지도 선택, ‘나만의 장소’ 저장 기능 포함) 두 가지 안으로 구체적으로 설계하여 팀에 제시하고 의견을 수렴. 설계안에는 AI가 제안하는 후보 수(예: 3~5개), 후보에 좌표 포함 방식, 장소명 교체 시 문장 템플릿 적용 방법을 명시.
- 정수현 — 크레딧 가격 UX 관련 제안(1개 크레딧 가격 ₩200 추가 건)을 정리해 전형선에게 전달하고, 디버그 앱에서 가격 표시가 최신 상태인지 확인해 피드백 제공.
