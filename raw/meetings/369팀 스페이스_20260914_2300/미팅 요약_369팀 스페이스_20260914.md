개요
주요 참가자 이동건, 정수현, 전형선이 앱 개발 프로젝트의 현재 상태를 검토하기 위해 모였습니다. 이동건은 개인적인 약속으로 인해 최근 기여가 제한되었지만 디자인 문서 및 초기 사용자 테스트 진행 상황을 공유했습니다. 정수현은 배포 전략 및 부하 테스트에 집중했으며, 전형선은 로깅 및 오류 보고 개선에 집중했습니다.
사용자 피드백은 앱에 대한 전반적으로 좋은 이해를 강조했으며, 사진 선택 기본값 및 타임라인 생성 중 알림 전환과 같은 사소한 UI 문제들이 있었습니다. 팀은 초기 사용자 혼란을 줄이기 위해 온보딩 튜토리얼 및 UI 요소를 개선할 계획입니다. 로깅 개선 및 새로운 버그 등록 페이지가 체계적인 문제 추적을 지원하기 위해 우선시되었습니다.
UI/UX 문제에는 어두운 모드에서 겹치는 알림, 작은 글꼴 크기, 비좁은 입력 필드가 포함되었습니다. 알림 위치 변경, 글꼴 크기 제한, 입력 중 불필요한 버튼 숨기기와 같은 솔루션이 진행 중입니다. AI API 사용에 대한 비용 최적화 노력은 모델 사용 및 토큰 수를 다양화하여 유망한 비용 절감을 보여주었습니다.
팀은 QA와 프로덕션 환경 간의 Google 계정 로그인 불일치 문제도 다루었으며, SDK 또는 서버 측 수정을 고려했습니다. 건강과 복지에 대해서도 간단히 논의하며 계절적 질병 위험 속에서 휴식을 권장했습니다. 전반적으로 회의는 기술 개선, 사용자 경험 및 다가오는 베타 테스트 단계 준비에 대한 조정된 노력을 강화했습니다.
상세 요약
프로젝트 진행 상황 및 작업
팀은 디자인 문서 업데이트, 메타 광고 탐색, 시각화 도구에 대한 지속적인 작업을 포함하여 프로젝트의 현재 진행 상황에 대해 논의했습니다. 그들은 이력서 작성 및 초기 피드백을 위해 지인과 앱을 공유하는 것과 같은 개인 작업을 완료하는 것의 중요성을 강조했습니다. 현재 초기 테스트가 진행 중이며 일부 사용자 피드백이 수집되었습니다.
이동건은 최근 소설을 쓰고 있어 프로젝트 작업이 제한되지만 디자인 문서를 업데이트하고 메타 광고를 탐색하고 있다고 공유했습니다.
이동건은 시각화 도구를 검토하고 있으며 내일까지 이력서 관련 작업을 완료할 것으로 예상하고 있습니다.
이동건은 앱을 다섯 명의 지인에게 배포하고 초기 리뷰를 받았으며, 퇴근 후 피드백에 대해 논의할 계획입니다.
정수현은 롤링 배포 및 AI 기반 부하 테스트 작업을 보고했습니다.
전형선은 로깅 개선 및 오류/충돌 로그 디자인에 집중하고 있으며, 주 중반까지 완료할 계획입니다.
앱 사용성에 대한 사용자 피드백
팀은 초기 앱 테스터로부터 받은 사용자 피드백을 검토하며, 사용자가 초기 우려에도 불구하고 앱을 전반적으로 잘 이해하고 있음을 주목했습니다. 사진 선택 및 타임라인 생성 중 알림 전환에 대한 혼란과 같은 특정 UI 문제들이 확인되었습니다. 팀은 이러한 문제들이 사소하지만 첫 사용자 경험 개선에 중요하다고 인정했습니다.
이동건은 사용자가 앱 설명을 명확하게 이해하고 AI 생성 질문이 유용하다고 보고했다고 전했습니다.
사용자들은 대화 내용을 검색할 수 없고 필수 사진 선택과 선택적 알림 간의 어색함에 대한 우려를 제기했습니다.
정수현은 사진 섹션이 처음에는 비어 보이는데, 사용자가 이를 어색하게 느꼈고 기본 사진 선택 상태가 모호하다고 언급했습니다.
전형선은 UI 색상 팔레트 문제를 인정하고 체크박스 및 튜토리얼 설명을 개선할 계획입니다.
이동건과 전형선은 초기 사용자 혼란이 예상되지만 더 나은 온보딩 및 UI 조정으로 완화할 수 있다고 논의했습니다.
로깅 및 오류 보고 개선
팀은 베타 테스트 후 분석을 지원하기 위해 로깅 및 오류 보고 개선을 우선시하고 있습니다. 그들은 로그 저장 비용을 최적화하고 오류 수준을 신중하게 설계할 계획입니다. 테스트 중 문제를 체계적으로 수집하고 추적하기 위해 버그 등록 페이지가 생성될 것입니다.
전형선은 비용 최적화를 염두에 두고 오류 및 충돌 로그 시스템을 설계하고 있으며, 주 중반까지 완료할 목표입니다.
이동건은 문제 및 진행 상황을 추적하기 위해 모바일 QA 문서에 버그 등록 페이지를 만들 것을 제안했습니다.
팀은 리뷰 및 해결을 용이하게 하기 위해 사소한 버그와 개선 사항도 문서화하기로 합의했습니다.
이동건은 두 가지 UI 관련 문제를 공유했습니다: 어두운 모드에서 버튼을 겹치는 흰색 스낵바와 메모 작성 중 입력 필드 방해.
전형선은 스낵바가 안드로이드 표준이며 UI 요소가 겹치지 않도록 표시를 조정할 계획이라고 확인했습니다.
앱 UI 및 UX 개선
여러 UI/UX 문제가 확인되었으며, 여기에는 겹치는 버튼 및 알림, 작은 글꼴 크기, 비좁은 입력 필드가 포함됩니다. 팀은 사용자 경험을 향상시키기 위해 알림 위치 변경, 글꼴 크기 제한 조정, 입력 중 불필요한 버튼 숨기기와 같은 잠재적 솔루션에 대해 논의했습니다.
이동건은 어두운 모드에서 흰색 스낵바 알림이 시각적으로 방해가 되고 버튼을 겹친다고 느꼈습니다.
전형선은 홈 화면 버튼에서 알림을 이동시켜 혼잡함을 줄일 계획입니다.
이동건과 정수현은 글꼴 크기 선호도에 대해 논의했으며, 앱 내에서 글꼴 크기 제한을 구현할 계획입니다.
이동건은 메모 입력 필드가 비좁게 느껴지며 텍스트 입력 중에는 플로팅 액션 버튼을 숨겨야 한다고 언급했습니다.
전형선은 입력 편안함을 개선하기 위해 줄 간격 및 버튼 가시성을 조정하기로 동의했습니다.
API 비용 최적화 및 배포 계획
팀은 API 사용 비용 및 다양한 단계에서 비용을 줄이기 위한 전략을 검토했습니다. 그들은 원활한 앱 출시 및 사용자 경험을 보장하기 위해 롤링 업데이트 및 강제 업데이트를 포함한 배포 접근 방식에 대해서도 논의했습니다.
이동건은 최근 단계별로 다른 AI 모델을 사용하여 비용을 거의 절반으로 줄여 약 ₩50로 보고했습니다.
목표는 토큰 최적화를 통해 비용을 ₩30-40로 추가로 줄이는 것입니다.
정수현은 안정성을 보장하기 위해 AI를 활용한 롤링 배포 및 부하 테스트를 처리하고 있습니다.
전형선은 로깅 업데이트가 강제 앱 업데이트를 필요로 한다고 확인했습니다.
팀은 앱 홍보는 출시 후에 시작할 수 없으므로 준비에 집중하고 있다고 인정했습니다.
사용자 계정 및 로그인 문제
팀은 Google 계정 선택 기능을 테스트하고 QA 및 프로덕션 환경 로그인 흐름에서 문제를 확인했습니다. 그들은 SDK 변경 또는 서버 측 분기를 통해 다양한 로그인 버전을 적절히 처리하는 것과 같은 잠재적 솔루션에 대해 논의했습니다.
정수현은 Google 계정 선택이 프로덕션에서 작동한다고 확인했습니다.
전형선은 QA에서 MLink를 통해 로그인할 때 프로덕션 릴리스를 사용하여 혼란을 초래한다고 관찰했습니다.
전형선은 로그인 흐름을 분기하거나 SDK에서 이를 처리할 것을 제안했지만 실행 가능성에 대해 확신하지 못했습니다.
팀은 필요에 따라 로그인 환경 불일치를 모니터링하고 해결하기로 합의했습니다.
건강 및 팀 복지
참석자들은 건강 문제, 특히 정수현의 감기 증상에 대해 간단히 논의하며 프로젝트의 힘든 기간 동안 휴식과 자기 관리의 중요성을 강조했습니다.
정수현은 감기 증상으로 몸이 좋지 않지만 일을 잘 관리하고 있다고 보고했습니다.
전형선은 물을 많이 마시고 건강을 우선시할 것을 권장했습니다.
이동건은 계절 변화가 질병 위험을 증가시킨다고 언급하며 주의를 촉구했습니다.
팀은 건강 문제에 대한 상호 지원과 이해를 표현했습니다.

- 전형선은 수요일이나 목요일까지 에러 및 크래시 로그 레벨을 포함한 로깅 시스템의 설계 및 구현을 완료해야 합니다.
- 이동건은 테스터의 타임라인 데이터 사용을 분석하고 팀과 실제 생활 정렬과 관련된 통찰이나 문제를 공유할 것입니다.
- 이동건은 로고 수집 전략에 대한 요약을 팀과 곧 정리하고 공유해야 합니다.
- 전형선은 롤링 업데이트와 관련된 현재 작업에 대한 강제 업데이트 구현을 진행할 것입니다.

- 이동건은 NI 쪽에 SQS를 구현하여 세션 동시성 제한을 처리하고 잠재적인 고부하 시나리오에 대비할 계획입니다.
