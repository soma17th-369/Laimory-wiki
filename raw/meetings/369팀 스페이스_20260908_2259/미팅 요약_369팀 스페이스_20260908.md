개요
주요 참가자 이동건, 정수현, 전형선은 회의 중 여러 기술 및 운영 주제에 대해 논의합니다. 이동건은 멘토 피드백 및 3버전 개발을 포함한 AI 프롬프트 개선 사항을 보고하며, 주말까지 출시를 목표로 하고 있습니다. 팀은 비디오 콘텐츠 제작을 계획하며, 오픈 소스 도구에도 불구하고 관련 비용을 인정합니다. 정수현은 AI 기반 UI 테스트를 지원하기 위해 에이전트 코어 인프라를 활성화하는 것을 우선시하며, 이동건은 신속한 구현을 약속합니다.
전형선은 데이터베이스 문제 해결 및 Spring Boot와 SSM 터널을 사용한 보안 관리 웹 인터페이스 개발에 대한 업데이트를 제공합니다. 앱 업데이트는 위치 권한 버그를 해결하여 추적 및 사용자 경험을 개선합니다. 팀은 특히 권한 부여 및 사용자 상호작용과 관련하여 온보딩 흐름에서의 문제를 식별하고, 준수 및 데이터 수집을 향상시키기 위해 진행 표시기 및 더 명확한 권한 안내와 같은 UI 개선을 고려합니다. 그들은 온보딩 완료 상태를 전환하는 테스트 API를 생성하는 것에 대해 논의하며, 사용의 용이성을 위해 인증되지 않은 상태로 유지하기로 합의합니다.
서버 인프라 논의는 비용 효율성으로 인해 콜백을 위해 기존 ALB를 사용하는 것을 선호합니다. 로깅 정책 변경으로 인해 사용자 계약 업데이트가 필요하며, 정수현과 전형선이 개정을 조율합니다. 이동건은 AI 능력 이상의 엔지니어링에서 인간의 역할을 강조하는 기술 강연에서의 통찰을 공유하며, 측정 가능한 기준과 책임의 필요성을 강조합니다. 마지막으로, 팀은 장학금 자격을 유지하기 위해 인프라 교육을 완료하는 것의 중요성을 강조하며, 일관된 참여에 대한 약속을 합니다.
상세 요약

이동건은 AI 출력을 개선하기 위해 프롬프트에 예제를 포함하라는 멘토의 조언을 설명합니다.
이동건은 3버전이 광범위한 작업과 문제 수정을 포함하고 있으며 금요일까지 배포할 계획이라고 언급합니다.
이동건은 출시 전에 이전 버전과 점수를 비교하여 개선 사항을 검증하겠다고 약속합니다.
비디오 콘텐츠 제작 및 비용
팀은 비디오 모델을 사용하여 비디오 콘텐츠를 제작할 계획이지만, 오픈 소스 모델조차도 서버 사용으로 인해 비용이 발생한다는 점을 인정합니다. 그들은 비디오 제작을 위한 양과 접근 방식에 대해 전략을 세우고 있으며, 아직 최종 결정을 내리지 않았습니다.
이동건은 비디오 모델 사용이 오픈 소스임에도 불구하고 비용이 필요하다고 말합니다.
이동건은 비디오 스토리보드를 계획하고 있지만 실제 제작 비용과 양은 아직 결정되지 않았다고 언급합니다.
에이전트 코어 인프라 및 UI 테스트
정수현은 AI를 통한 UI 테스트를 용이하게 하기 위해 시스템이 에이전트 코어 인프라에서 작동할 수 있도록 우선순위를 두어야 한다고 요청합니다. 이동건은 이를 신속하게 해결하겠다고 동의하며, 다음 날까지 사용 가능하도록 할 계획입니다.
정수현은 AI 기반 UI 테스트를 위한 에이전트 코어 인프라의 중요성을 강조합니다.
이동건은 내일까지 사용 가능하도록 인프라 설정을 해결하겠다고 약속합니다.
관리 웹 및 데이터베이스 문제
전형선은 이전 데이터베이스 문제 해결 및 Spring Boot를 사용한 관리 웹 인터페이스 개발에 대한 진행 상황을 보고합니다. 관리 웹은 API 접근을 로컬 요청으로 제한하고 SSM 터널과 통합하여 보안 연결을 고려하며 모바일 버전 관리를 포함합니다.
전형선은 보안을 위해 제한된 API 접근으로 관리 웹 개발을 설명합니다.
전형선은 웹 인터페이스에서 안전한 API 호출을 가능하게 하기 위해 SSM 터널을 사용할 계획입니다.
정수현은 관리 웹이 거의 완성되어 배포 준비가 되었다고 언급합니다.
앱 업데이트 및 위치 권한 수정
전형선은 위치 권한 문제를 해결하는 최근 앱 업데이트에 대해 자세히 설명하며, 특히 '항상 허용' 권한이 적절한 위치 추적을 가능하게 하는지 확인합니다. 그들은 실험 탭에 의존하는 UI 요소를 재구성하고 사용자 경험 및 데이터 수집을 개선하기 위한 추가 업데이트를 계획합니다. 팀은 특히 권한 부여 및 사용자 상호작용과 관련하여 온보딩 흐름에서의 문제를 식별하고, 준수 및 데이터 수집을 향상시키기 위해 진행 표시기 및 더 명확한 권한 안내와 같은 UI 개선을 고려합니다.
전형선은 '항상 허용' 추적을 지원하기 위해 위치 권한 토글 수정 사항을 확인합니다.
전형선은 위치 표시를 위한 실험 UI 탭에 대한 의존성을 식별하고 리팩토링할 계획입니다.
전형선은 성공적인 앱 업데이트 배포를 보고하고 홈 화면 개편을 포함한 추가 업데이트를 계획합니다.
이동건은 온보딩 중 권한의 중요성을 강조하기 위해 진행 표시줄이나 체크리스트 스타일의 표시기를 사용할 것을 제안합니다.
이동건과 정수현은 사용자가 더 강력한 UI 집행이나 더 명확한 안내 없이 중요한 온보딩 단계를 건너뛸 수 있다는 우려를 표명합니다.
전형선은 온보딩 흐름을 최적화하고 권한 부여를 단순화할 방법을 탐색하기로 동의하며, 중복 프롬프트를 제거하는 것을 포함합니다.
이동건은 Android 권한 옵션의 복잡성과 위치 및 사진 접근을 위한 단일 권장 설정으로 표준화할 필요성을 강조합니다.
전형선은 사용자에게 더 명확한 안내를 제공하고 '항상 허용' 권한을 한 번에 활성화하기 위해 시스템 설정으로 직접 안내할 가능성을 계획합니다.
이동건과 전형선은 온보딩 효과성을 모니터링하기 위해 권한 상태 및 데이터 수집 성공 지표를 기록하는 것에 대해 논의합니다.
사용자 온보딩 및 테스트 API
팀은 로그인 후 온보딩 화면이 나타나지 않는 문제에 대해 논의하고 테스트 목적으로 온보딩 완료 상태를 전환하는 간단한 API를 만들 계획입니다. 그들은 이러한 API를 사용의 용이성을 위해 인증되지 않은 상태로 유지하기로 합의하지만 나중에 제거할 계획입니다.

전형선은 인증 없이 API를 사용하기로 동의하고 이를 테스트 전용으로 분류할 것을 제안합니다.
이동건과 전형선은 온보딩 화면을 활성화하기 위해 데이터 소스 권한을 재설정하는 것에 대해 논의합니다.

이동건은 서버 콜백을 위한 두 가지 ALB 옵션: 기존 공용 ALB 대 내부 ALB를 설명합니다.
정수현과 이동건은 인터넷 노출에도 불구하고 기존 ALB를 사용하는 것이 더 비용 효율적이라고 동의합니다.
이동건은 ALB 연결을 테스트하고 결과를 팀과 공유할 계획입니다.

전형선은 로그 수집에 영향을 미치는 정책 변경 사항과 사용자 계약 업데이트 필요성을 강조합니다.
정수현은 AI 지원으로 개인정보 보호 정책을 개정하고 내일까지 변경 사항을 적용하겠다고 약속합니다.
