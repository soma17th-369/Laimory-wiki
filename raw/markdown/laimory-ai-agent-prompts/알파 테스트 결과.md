# Laimory AI 타임라인 알파 테스트 결과

## 공통 관찰

- 모든 Agent가 Laimory의 high-level 목표를 공유해야 한다. 최종 결과는 센서와 알림의 요약을 넘어 사용자가 실제로 무엇을 했는지 회상할 수 있는 일기형 타임라인이어야 한다.
- 위치 기록은 체류와 이동을 나열하는 용도가 아니라 그 시간에 사용자가 했을 가능성이 높은 활동을 복원하는 근거로 사용해야 한다.
- UTC 변환과 하루 경계 문제가 여러 테스트에서 반복되었다. 원본 시각, timezone, 요청 날짜 window를 전체 파이프라인에서 일관되게 처리해야 한다.
- 이동 구간이 지나치게 잘게 나뉘거나 일부 이동·귀가 기록이 누락되는 문제가 반복되었다. 연속 이동은 실제 여정 단위로 병합하고 모든 raw item의 처리 상태를 추적해야 한다.
- 사진, 캘린더, 위치는 하루 복원에 중요한 근거다. 정상적으로 수집된 항목은 candidate, fragment, noise, failure 중 하나의 상태를 갖고 최종 사용 여부까지 추적되어야 한다.
- 사진은 촬영 시각과 내용을 함께 사용해야 한다. 서로 다른 시간과 활동의 사진은 각각 해당 사건에 귀속하고, 하나의 사진은 최종 타임라인에서 한 event에만 표시해야 한다.
- 알림은 예약, 결제, 이동, 업무, 소통과 연결되는 맥락으로 해석해야 한다. 같은 시간대와 주제의 결제·송금·대화 알림은 하나의 실제 사건을 함께 설명할 수 있다.
- 하루의 마지막에는 마지막으로 확인된 위치와 활동, 귀가 근거, 데이터 수집 공백을 구분해 표현해야 한다.
- debug 환경에서는 타임라인 상단에 `taskId`를 표시하면 테스트 결과 추적이 쉬워진다.

#### 좋은 점

- 이동 시간이 비교적 정확하게 표현되었다.

#### 관찰된 문제와 개선 방향

- 오전 11시 42분의 햄버거 사진과 오후 5시 18분의 텐동 사진이 하나의 식사 event로 묶였고 event 시간도 실제와 맞지 않았다. 촬영 시각과 사진 내용을 함께 사용해 서로 다른 식사 event로 구성해야 한다.
- 식사를 별도 event로 구성하면 센터필드 event에는 해당 식사 사진을 중복 표시하지 않는 편이 자연스럽다.
- 같은 사진이 여러 event에 표시되었다. 하나의 사진 rawId는 최종적으로 정확히 하나의 event에 귀속해야 한다.
- 캘린더에 센터필드 장소 정보가 없어 센터필드 체류와 AI 인프라 교육이 별개 event가 되었다. 교육 일정의 시간, 센터필드 체류, 전후 이동을 연결해 교육이 해당 장소에서 진행되었을 가능성을 추론할 필요가 있다.
- 귀가 흐름이 최종 타임라인에 나타나지 않았다. 실제 귀가 근거와 데이터 수집 공백을 확인하고, 확인 가능한 범위까지 하루의 마무리를 표현해야 한다.

#### 관찰된 문제와 개선 방향

- 지역 간 장거리 이동이 여러 개의 작은 이동으로 분리되었고 주요 출발 교통 거점이 제대로 인식되지 않았다. 출발지, 주요 도착지, 도착 후 지역 내 이동을 하나의 상위 여정으로 복원해야 한다.
- 공덕역 인근에서 먹은 간단한 식사가 다른 장소 또는 시간의 사건처럼 표현되었다. 어떤 sourceRefs가 식사 장소와 시간을 결정했는지 추적할 수 있어야 한다.
- 소마 센터에서 진행한 활동이 최종 결과에 나타나지 않았다. 캘린더, 위치, 알림을 연결해 중심 활동을 복원해야 한다.
- 근거가 불분명한 기상 event가 생성되었다. 수면 종료 시각과 기상 event의 근거 관계를 확인해야 한다.
- 저녁 식사 사진이 최종 결과에 나타나지 않았다. 선택 사진의 전체 처리 상태와 event 귀속을 확인해야 한다.
- 하루 동안 이어진 여자친구와의 메시지가 부자연스러운 하나의 긴 활동으로 표현되었다. 메시지의 실제 간격을 보존하면서 상대, 관계, 주제, 소통의 의미를 설명할 필요가 있다.
- 모든 주요 event가 위치 또는 위치 부재 상태와 연결되지 않았다. Location Agent가 생성한 이동·체류 흐름과 데이터 공백 정보를 Timeline에서 보존해야 한다.
- 최종 결과가 딱딱한 기록처럼 읽혔다. 하루의 중심 사건과 관계를 자연스러운 일기체로 구성해야 한다.
- 귀가 기록이 나타나지 않았다. 실제 raw 누락과 데이터 수집 공백을 구분해야 한다.
